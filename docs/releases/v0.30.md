# v0.30 Update Release

Release date: 2026-06-02

## Highlights

- Added per-subject difficulty settings for each entered subject.
- Added three difficulty levels: easy, normal, and weak.
- Weighted generated plans so weak subjects appear more often than normal or easy subjects.
- Added example subject difficulty values to the example input button.
- Added a generated-plan summary that shows the selected difficulty for each subject.
- Improved topic matching from test range memos so subject-specific topics are reflected more clearly.

## UI Improvements

- Updated the hero badge to announce the v0.30 update release.
- Added a release note to the top of the web app so users can immediately see what changed.
- Improved the subject difficulty settings layout for smartphone-width screens.

## Verification

- Confirm that entering subjects displays per-subject difficulty selectors.
- Confirm that the example input button fills subject difficulty examples.
- Confirm that generated plans include a subject difficulty summary.
- Confirm that weak subjects are weighted more heavily in plan assignment.
