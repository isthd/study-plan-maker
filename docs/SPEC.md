# Study Plan Maker Specification

## Purpose

Study Plan Maker helps students create a simple and realistic study schedule.

The first version focuses on students who want to plan their test study time easily.

## Basic Input Fields

### 1. Subjects

Users enter the subjects they want to study.

Example:

- English
- History
- Japanese
- Science

### 2. Available Study Days

Users enter the days when they can study.

Example:

- Monday
- Tuesday
- Thursday
- Saturday

### 3. Target Score

Users enter their target score.

Example:

- 50 points or higher
- 70 points or higher

### 4. Difficulty Level

Users choose how hard the plan should be.

Options:

- Easy
- Normal
- Hard

## Future Input Fields

These fields may be added in future versions.

### Unavailable Days

Users can enter days when they cannot study.

Example:

- Friday
- Rehabilitation days
- Family events

### Rest Days

Users can choose days when they do not want to study.

Example:

- Friday
- Sunday

### Subject Difficulty

Users can set difficulty for each subject.

Example:

- English: Easy
- History: Normal
- Math: Hard

## Version 0.1 Scope

Version 0.1 includes:

- Subjects
- Available study days
- Target score
- Overall difficulty level
- Simple text-based study plan output

## Not Included in Version 0.1

Version 0.1 does not include:

- Calendar layout
- Image export
- Login system
- AI-generated plans
- Automatic date calculation
