# 科目ごとの苦手度設定を追加する

## 概要

ユーザーが科目ごとに苦手度を設定できるようにし、苦手な科目を勉強計画に多めに反映できるようにする。

## 背景

現在は入力された科目を順番に割り当てているため、得意・不得意にかかわらず各科目の出現回数がほぼ同じになる。苦手な科目により多くの学習時間を割けるようにすることで、ユーザーにとってより実用的な計画にする。

## やりたいこと

- 科目ごとに苦手度を設定できるUIを追加する
- 苦手度は以下の3段階にする
  - やさしい
  - ふつう
  - 苦手
- 設定した苦手度を勉強計画の作成ロジックに反映する
- 「苦手」の科目が「ふつう」「やさしい」より多めに計画へ出るようにする
- 未設定の科目は「ふつう」として扱う

## 受け入れ条件

- [ ] 科目を入力した後、各科目の苦手度を設定できる
- [ ] 苦手度の選択肢として「やさしい」「ふつう」「苦手」が表示される
- [ ] 苦手度を設定しなくても既存の計画作成が壊れない
- [ ] 「苦手」に設定した科目が計画内で相対的に多く割り当てられる
- [ ] 入力例ボタンを押したとき、苦手度設定の例も分かる
- [ ] スマートフォン幅でも苦手度設定UIが使いやすい

## 実装メモ

- 科目の重み付け例
  - やさしい: 1
  - ふつう: 2
  - 苦手: 3
- 計画作成時に、科目リストを重みに応じて展開してから割り当てるとシンプルに実装できる
- テスト範囲メモの反映と組み合わせても、科目名と内容がずれないように注意する
