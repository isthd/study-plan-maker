# Study Plan Maker

Study Plan Maker は、学生がテスト勉強の計画をかんたんに作れるオープンソースのWebアプリです。

科目、勉強できる日、勉強できない日、予定メモ、テスト範囲メモを入力すると、無理のないシンプルな勉強計画を作成できます。

iPad、スマートフォン、パソコンで使いやすいように設計しています。

## デモ

以下のページから実際に試すことができます。

https://isthd.github.io/study-plan-maker/

## 主な機能

- 科目と勉強できる日から、シンプルな勉強計画を作成
- 勉強できない日を計画から除外
- リハビリ、休み、予定、通院などの予定メモに対応
- カレンダーや予定表のスクリーンショットをOCRで読み取り
- OCR結果を編集できるテキスト欄を表示
- テスト範囲メモをもとに、科目ごとの内容を計画に反映
- テスト範囲メモから科目ごとの学習トピックを反映
- 科目ごとに「やさしい」「ふつう」「苦手」の苦手度を設定
- 苦手な科目を計画に多めに反映
- カード形式で見やすい勉強計画を表示
- 1つのHTMLファイルで動作
- 外部OCR APIキー不要
- iPadやスマートフォンでも見やすいレイアウト

## このアプリでできること

Study Plan Maker は、次のような悩みを解決するためのアプリです。

- どの科目を何曜日に勉強すればいいか分からない
- 忙しい日や休みたい日を避けて計画を立てたい
- テスト範囲を見ながら勉強計画を作りたい
- カレンダーのスクショを予定作成に使いたい
- シンプルで見やすい勉強計画を作りたい

## OCR機能について

このアプリでは、Tesseract.js を使って画像内の文字を読み取ります。

アップロードできる画像の例：

- カレンダーアプリのスクリーンショット
- 学校の予定表
- テスト範囲の画像
- メモアプリのスクリーンショット
- 手元の予定メモ画像

OCRで読み取った文字は、テキスト欄に表示されます。  
必要に応じて手で修正してから、予定メモとして使うことができます。

## OCRの注意点

OCRは完璧ではありません。

次のような画像では、読み取りミスが起きることがあります。

- 文字が小さい
- 画像がぼやけている
- 背景が複雑
- アイコンや装飾が多い
- 日本語、数字、記号が混ざっている
- カレンダーの文字が細かすぎる

より正確に使うために、OCR結果はそのまま使わず、少し確認して直すことをおすすめします。

## APIキーは不要

このアプリは、外部OCR APIキーを必要としません。

OCR処理は、Tesseract.js を使ってブラウザ上で行います。

ただし、Tesseract.js をCDNから読み込む場合があるため、アプリの読み込み時にはインターネット接続が必要になることがあります。

## 使い方

1. デモページを開く
2. 勉強したい科目を入力する
3. 勉強できる日を入力する
4. 勉強できない日を入力する
5. 目標点と難易度を入力する
6. 必要なら、カレンダーや予定表の画像をアップロードしてOCRを実行する
7. 予定メモやテスト範囲メモを入力する
8. 「勉強計画を作る」ボタンを押す

## 入力例

### 科目

```text
英語, 歴史, 国語
```

### 勉強できる日

```text
月曜日, 火曜日, 水曜日, 木曜日, 金曜日, 土曜日
```

### 勉強できない日

```text
金曜日
```

### 予定メモ

```text
火曜日 リハビリ
土曜日 予定あり
```

### テスト範囲メモ

```text
英語: 不定詞、Unit 5
歴史: 江戸時代
国語: 漢字、本文読解
```

## 現在の制限

Study Plan Maker はまだ開発初期のプロジェクトです。

現在の制限は以下の通りです。

- 本物のAI機能はまだ使っていない
- テスト範囲の読み取りは簡易的
- OCRの精度は画像の品質に左右される
- データは永続保存されない
- カレンダーアプリとは自動連携しない
- バックエンドサーバーは使っていない
- 長期的な学習計画にはまだ弱い

## 開発の目標

このプロジェクトの目標は、学生が現実的な勉強計画を立てやすくすることです。

特に重視していること：

- シンプルな操作
- 分かりやすいデザイン
- iPadで使いやすいレイアウト
- アカウント不要
- 難しい設定なし
- 小さな改善を積み重ねる開発
- オープンソースとして公開すること

## このプロジェクトを作った理由

多くの学生にとって、テスト勉強の計画を立てるのは意外と難しいです。

ただ科目を並べるだけでは、現実的な計画にはなりません。

実際には、次のような予定も考える必要があります。

- 忙しい日
- 休みたい日
- リハビリの日
- 学校行事
- 家の予定
- テスト範囲
- 苦手科目
- 目標点
- 実際に勉強できる時間

Study Plan Maker は、こうした現実の予定を考えながら、シンプルで続けやすい勉強計画を作るためのツールです。
