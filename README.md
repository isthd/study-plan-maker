# Study Plan Maker

Study Plan Maker is an open-source tool that helps students create a realistic study schedule based on test subjects, weak areas, available days, and rest days.

## Goal

The goal of this project is to make it easier for students to plan their study time without feeling overwhelmed.
## Roadmap

### Version 0.1
- Decide the basic input fields
- Create a simple text-based study plan
- Add Japanese support

### Version 0.2
- Add unavailable days
- Add difficulty settings
- Improve the study plan format

### Future
- Export the plan as an image
- Make an iPad-friendly interface
- Add calendar-style layout
